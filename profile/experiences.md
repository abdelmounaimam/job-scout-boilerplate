# Experience canon — the single source of truth

**This file is the original. Everything else is a copy or a derivative.**

| Surface | Regime | How |
|---|---|---|
| LinkedIn profile | exact mirror | any change here gets pushed to the live profile |
| Portfolio / personal site | exact mirror | |
| Resume | **derived, not mirrored** | `cv/` holds the base, `cv/tailored/` holds per-posting versions that diverge freely |

Any change to an experience starts **here**, then propagates. A change that has not propagated yet gets written down as debt at the bottom of this file, because an un-noted divergence is discovered by a recruiter, not by you.

⚠️ **Figures that are fine on a resume are not always fine in public.** A resume goes to a named recruiter; a portfolio and a LinkedIn profile are indexed and readable by the current employer. Decide per figure, and note the decision.
